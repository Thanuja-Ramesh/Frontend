1.JavaScript is a programming language used to create dynamic and interactive web pages.
2.A variable is a named storage location used to store a value.
Example:
var userName = "Java";
3.Declaration means creating a variable without assigning a value.
Example:
var userName;
Here:
var → Keyword
username → Variable Name
This is called variable declaration.
4. Initialization means assigning an initial value to a variable.
Example:
var userName = "React";
Here:
var userName → Declaration
= "React" → Initialization / Assignment
5.The assignment operator is:
=
It is used to assign a value to a variable.
Example:
var userName;
userName = "React";
6.var is the traditional JavaScript variable declaration keyword.
Example:
var username = "React";

let was introduced in ES6.
ES6 means ECMAScript 2015.
Example:
let city = "Chennai";

const was also introduced in ES6.
const is used when the variable binding should not be reassigned.
Example:
const course = "JavaScript";
7.var: Accessible throughout the entire function or globally if outside a function.
 let / const: Confined strictly to the nearest curly-brace block
8.ES6
ES6 stands for ECMAScript 2015.
ES6 introduced many modern JavaScript features.
Important variable declarations:
var
let
const
9.A JavaScript engine is a specialized computer program that parses, interprets, and executes JavaScript code by translating human-readable source code into machine-readable instructions that a computer's CPU can run
10.The V8 engine is Google’s open-source, high-performance JavaScript and WebAssembly engine written in C++. Its primary job is to take the high-level JavaScript code that humans write and translate it directly into low-level machine code that a computer's processor can execute
