Introduction to JavaScript

  • Language of the Web: JavaScript is the primary programming language that powers interactivity on the web.
  • DOM Manipulation: JavaScript can dynamically update and modify both HTML content and CSS styles in real time.
  • Data Processing: JavaScript can calculate, manipulate, validate, and manage data across client and server environments.

Variables

A variable is a container used to store data values in JavaScript.

JavaScript provides three primary keywords for declaring variables:

  1. var

    The traditional (pre-ES6) way of declaring variables. Function-scoped and hoisted.

  2. let

    Block-scoped variable declaration used when the value is expected to change.

  3. const

    Block-scoped declaration used when the variable reference should remain constant and not be reassigned.

Features var let const
Reassign Value Yes Yes No
Redeclare Yes No No
Scope Global / Function Scope Block Scope Block Scope

Data Types

Primitive Data Types

Primitive data types represent single, immutable values stored directly in the stack memory.

  1. String:

    Represents textual data enclosed in single quotes, double quotes, or backticks.

    Example: "Hello", 'World', `JavaScript`

  2. Number:

    Represents both integers and floating-point numbers (decimals), as well as special values like Infinity, -Infinity, and NaN.

    Example: 42, 3.14, -100

  3. BigInt:

    Used for integers of arbitrary length that exceed the safe limit of the standard Number type.

    Example: 9007199254740991n

  4. Boolean:

    Represents a logical entity with only two possible values: true or false.

    Example: true, false

  5. Undefined:

    Automatically assigned to a variable that has been declared but not yet initialized with a value.

    Example: let x; // undefined

  6. Null:

    Represents an intentional, explicit absence of any object value or reference.

    Example: let user = null;

  7. Symbol:

    Introduced in ES6, represents a unique and immutable identifier often used as private object property keys.

    Example: Symbol("id")

Operators

  1. Arithmetic Operators

    Perform mathematical calculations on operands.

    Example: +, -, *, /, % (remainder), ** (exponent)

  2. Assignment Operators

    Assign values to variables, optionally combined with calculations.

    Example: =, +=, -=, *=, /=

  3. Comparison Operators

    Compare two values and return a boolean (true or false).

    Example: ==, === (strict equality), !=, !==, <, >, <=, >=

  4. Logical Operators

    Determine logic between expressions or boolean values.

    Example: && (AND), || (OR), ! (NOT)

  5. Ternary Operator

    A shorthand conditional expression with three operands.

    Example: condition ? exprIfTrue : exprIfFalse

  6. Type & Relational Operators

    Evaluate data types or object property relationships.

    Example: typeof, instanceof, in

Conditional Statements

Conditional statements allow your code to make decisions and execute different branches of code based on dynamic conditions.

  1. The if Statement

    Executes a code block only if the specified condition evaluates to true.

  2. The if...else Statement

    Provides an alternative block of code that runs when the initial condition is false.

  3. The if...else if...else Chain

    Evaluates multiple distinct conditions in sequence until one matches.

  4. The switch Statement

    Matches an expression's value against multiple case clauses for clean branching logic.

  5. The Ternary Operator (? :)

    A concise single-line expression format for conditional evaluation.

Loops

Loops repeatedly execute a block of code while a specified condition is true, automating repetitive tasks efficiently.

  1. Standard for Loop

    Best suited when you know in advance how many times you need to iterate.

  2. while Loop

    Checks the condition before each iteration, executing as long as the condition evaluates to true.

  3. do...while Loop

    Guarantees that the code block runs at least once before testing the condition.

  4. for...of Loop

    Clean modern syntax to iterate over values of iterable objects (Arrays, Strings, Sets, Maps).

  5. for...in Loop

    Iterates over all enumerable keys and properties of an object.

Non-Primitive Data Types

Non-primitive data types (reference types) store a memory reference pointing to the location in the heap memory where the actual data resides.

Arrays

An array is an ordered list used to store multiple values under a single variable name. Under the hood, arrays are specialized objects with numeric keys (indexes) and built-in methods.

Objects

An object is a collection of key-value pairs. Keys are typically strings or symbols, and values can be any valid JavaScript type, including primitives, functions, or other objects.

Functions

A function is a reusable block of code designed to perform a specific task when invoked.

  1. Function Declaration:

    A traditional named function declared with the function keyword. Hoisted to the top of its scope.

  2. Function Expression:

    A function assigned directly to a variable. Not hoisted.

  3. Arrow Functions:

    Introduced in ES6, provides concise syntax and lexically binds this from its enclosing context.

  4. Anonymous Functions:

    Functions defined without a name, commonly passed as callbacks or event handlers.

Scope

Scope determines the visibility and accessibility of variables, functions, and objects across different parts of your code.

  1. Global Scope:

    Variables declared outside of all functions or blocks belong to the global scope and are accessible anywhere.

  2. Function Scope (Local Scope):

    Variables declared inside a function are accessible only within that function.

  3. Block Scope:

    Introduced in ES6; variables declared with let and const are strictly bound to the nearest enclosing pair of curly braces {}.

    • let and const are block-scoped.
    • var is NOT block-scoped and leaks outside curly brackets.

Hoisting

Hoisting is JavaScript's default behavior of moving variable, function, and class declarations to the top of their containing scope during compilation before execution.

Temporal Dead Zone (TDZ)

The Temporal Dead Zone (TDZ) is the period between the beginning of a block scope and the line where a let or const variable is declared. Accessing the variable before its initialization results in a ReferenceError.

Difference between ES5 and ES6+ in JavaScript

ES5: ECMAScript 5 standard released in 2009.

ES6+: ECMAScript 2015 and subsequent modern ECMAScript standards.

ES5 (Legacy) ES6+ (Modern)
Uses var for variable declarations Uses let and const
Traditional function declarations and expressions Arrow functions (=>) and concise methods
String concatenation using + operator Template literals with interpolation (`Hello ${name}`)
Prototype-based inheritance functions Native class syntax with extends
Manual property assignment Destructuring assignment for Arrays and Objects
Manual fallback checks for arguments Default function parameter values
Callback-based asynchronous flow Promises, async/await syntax
Standard for and for...in loops for...of loop and iterable protocols
CommonJS / IIFE module patterns Native ES Modules (import / export)
