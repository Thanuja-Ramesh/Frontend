What is React?

React is an open-source JavaScript library used to build interactive and reusable user interfaces, especially for web applications. React was created at Facebook and was open-sourced in 2013. Today it is maintained by Meta and the open-source community. React mainly focuses on the UI layer of an application.

In traditional JavaScript applications, developers manually select DOM elements and update them whenever data changes. React provides a declarative and component-based approach. We describe what the UI should look like for the current data/state, and React handles the necessary rendering and DOM updates.

Is React a library or framework?

React is a library, not a framework. Specifically, it is an unopinionated JavaScript library focused exclusively on the "view layer" of an application—meaning its primary job is building user interfaces, handling rendering, and managing UI updates.

What is a component?

A component is a reusable piece of UI. In modern React, components are commonly JavaScript functions that return JSX.

For example, instead of writing navbar code repeatedly, we can create one "Navbar" component and use it wherever required. Components make applications easier to divide into manageable pieces.

What is Virtual DOM?

Virtual DOM is a common term for React's in-memory representation of the UI. React uses its internal tree structures to determine what the UI should look like based on the latest component output.

When state changes, React renders the affected component logic again, creates the next representation, determines the necessary changes, and then commits the required updates to the browser DOM.

What ix reconciliation?

Reconciliation is the process React uses to determine how a newly rendered element/component tree relates to the previous one and what updates are necessary.

When props or state change, React renders again. During reconciliation, React compares the new element tree with the previous tree, preserves or replaces component instances where appropriate, and determines what work needs to be committed to the DOM.
