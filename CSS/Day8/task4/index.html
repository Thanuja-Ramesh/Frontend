HTML

HTML stands for HyperText Markup Language, and it is the standard language used to create and structure the framework of all web pages. Think of it as the skeleton of a website. It provides the core organization that web browsers read to render text, images, and links correctly

CSS

CSS, short for Cascading Style Sheets, is the standard style sheet language used to dictate the visual presentation, layout, and design of web page

JavaScript

Along with HTML and JavaScript, it is a core technology underpinning the World Wide Web

React

React is a free, open-source JavaScript library used for building user interfaces (UIs). Developed and maintained by Meta (formerly Facebook), it handles the "view" layer of web and mobile applications. Instead of refreshing the entire page when data changes, React dynamically updates only the specific sections that need altering, making websites much faster and smoother to use

Node.js

Node.js is a free, open-source, cross-platform JavaScript runtime environment that allows developers to execute JavaScript code outside of a web browser.
